# Attendly — Student Attendance Tracker

A small college presentation project with HTML and CSS for the frontend and a Python backend.

## Live presentation app

Open: https://attendly-student-tracker.onrender.com

Demo login: **teacher** / **teach123**

## Features

- Teacher login and logout
- Sample class of 10 students
- Attendance by date: Present, Absent, Late, or Not marked
- Attendance summary and percentage
- Python handles form submissions and saves records to JSON

This is a learning demo with sample credentials. Do not enter real student information. The free host may pause after inactivity, so the first page load can take a little longer. Saved attendance can reset when the service restarts.
